# 🎮 My GameMaker Project

A 2D top-down movement game made in GameMaker Studio.

---

## 🧠 About the Game

This is a simple prototype featuring:
- Smooth WASD movement
- Sprinting with Shift
- Basic wall collision
- Direction-based animations
- Restart key for testing

The goal of this project was to learn movement systems, collisions, and basic game structure in GameMaker.

---

## 🎮 Controls

- **WASD** – Move/navigate menus
- **Shift** – Sprint
- **R** – Restart game
- **Esc** – Exit menu
- **z** – sometimes select
- **x** – Exit menu/back
- **m** – open menu

---

## ⚙️ Features

- Top-down 4-direction movement system
- Collision with walls (`obj_wall`)
- Sprint mechanic with speed change
- Direction-based sprite system
- Simple depth sorting using Y position

---

## 🛠️ Built With

- GameMaker Studio 2 / 2024
- GML (GameMaker Language)

---

## 📁 Project Structure

- `/objects` – game objects (player, walls, etc.)
- `/sprites` – character and environment sprites
- `/rooms` – level layouts
- `/scripts` – movement and logic systems
